# Smartsite graao — Antigravity Starter V3.0

Workspace específico para graao, adaptado do starter V2.1. Ainda não é o website implementado.

## Início
1. Extraia o ZIP e abra a pasta inteira no Google Antigravity.
2. Adicione os ativos oficiais e documentos disponíveis sem segredos; o briefing já está preenchido.
3. Cole o comando de `START_HERE.md` no agente.
4. O agente deve ler integralmente os arquivos, pesquisar fontes autorizadas, auditar produto, criar plano e implementar o website funcional no workspace.
5. Revise o preview local, evidências, QA, pendências e autorize publicação separadamente.

## Arquivos
- `SMARTSITE_MASTER_PROMPT.md` — 33 seções de execução, do diagnóstico à entrega; arquitetura SaaS nacional, design e interatividade.
- `BUSINESS_BRIEF.md` — dados da graao e lacunas.
- `START_HERE.md` — comando de ativação.
- `documents/` — marca/copy, contrato de experiência e registro de evidências.
- `references/` — blueprint adaptado e original histórico.
- `assets/` — espaço para ativos oficiais.
- `docs/00–14` — registros de trabalho, sitemap proposto e QA. Status de desenvolvimento NOT STARTED.

## Estratégia
Uma pergunta comercial, uma plataforma, Brasil, uma conversão principal. Camadas Core + Funcionalidades + Soluções/casos de uso. Sem páginas geográficas artificiais. Sem menções a concorrentes. Sem assinatura não aprovada. Mobile first, Magic UI Pro como referência de componentes, UX interativa, SEO/AEO/GEO e evidências reais.

## Permissões
Não publique, altere DNS, crie cobranças, envie leads reais ou exponha segredos sem autorização. Não confunda starter com produto homologado. Código, dependências e preview serão construídos pelo agente. Os gates visual e interativo são obrigatórios; sem evidência, status PARTIAL.
