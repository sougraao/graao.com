A ação é o que o workflow faz depois do gatilho: enviar uma mensagem, mudar um contato, chamar a IA, esperar. A lista abaixo segue os grupos do editor de workflows.

## Telefonia

| Ação | Para que serve |
| --- | --- |
| **Ligar para o contato** | Liga primeiro para o telefone da equipe e, quando alguém atende, completa a ligação com o contato, mostrando o número da Graao. A ligação aparece em Conversas e no relatório de ligações e dispara Ligação terminou. |
| **Deixar recado por ligação** | Liga para o contato e, quando cai na caixa postal (ou alguém atende), fala o texto ou toca o áudio e desliga. |
| **Adicionar ao discador** | Coloca o contato na fila do discador (Conversas → Discador), para a equipe ligar em sequência. Contatos sem telefone ou em não perturbe ficam de fora. |
| **Ligação do Voice AI** | Um agente de IA publicado liga para o contato e conversa por voz, com a base de conhecimento dele e o objetivo desta etapa. Pode transferir para a equipe, encerrar ou marcar um horário do serviço escolhido. A transcrição vai para Conversas e dispara Ligação do Voice AI terminou. Usa a OpenAI de quem salvou o fluxo. |
| **Validar telefone** | Consulta o telefone do contato (Twilio Lookup): se o número existe e o tipo de linha. Guarda em `{{vars.telefone_status}}` (valid ou invalid) e `{{vars.telefone_tipo}}` e dispara Telefone validado. |
| **URA: falar ou tocar** | Fala um texto ou toca um áudio para quem ligou e segue para a próxima etapa. Só funciona em fluxos que começam por Início da URA, durante a ligação. |
| **URA: coletar dígitos** | Fala o menu e espera a pessoa digitar no teclado. Os dígitos ficam em `{{vars.nome}}`: use Se / Senão para cada opção. Sem resposta, a variável fica vazia. Só funciona em fluxos que começam por Início da URA, durante a ligação. |
| **URA: transferir ligação** | Toca nos telefones da equipe (um por linha, todos ao mesmo tempo) e conecta quem atender. O resultado fica em `{{vars.ivr_transferencia}}` (completed, no-answer, busy). Só funciona em fluxos que começam por Início da URA, durante a ligação. |
| **URA: gravar recado** | Fala o aviso e grava o recado depois do bipe. O recado vai para Conversas e o link fica em `{{vars.ivr_gravacao}}`. Só funciona em fluxos que começam por Início da URA, durante a ligação. |
| **URA: desligar** | Fala uma despedida (opcional) e encerra a ligação. As etapas seguintes que não são de URA continuam. Só funciona em fluxos que começam por Início da URA, durante a ligação. |

## Marketing

| Ação | Para que serve |
| --- | --- |
| **Enviar conversão para a Meta** | Manda um evento do contato para o seu Pixel da Meta pela API de Conversões (como Lead ou Compra), para os anúncios otimizarem com dados do CRM. E-mail, telefone e nome vão com hash (SHA-256). Precisa do Pixel em Marketing → Rastreamento e do Meta Ads conectado em Marketing → Anúncios. |
| **Enviar evento para o Google Analytics** | Manda um evento do contato para a sua propriedade do GA4 (Measurement Protocol), como lead gerado ou compra, com valor opcional. O contato vai só com um identificador da Graao (nada de e-mail ou telefone). Precisa do ID de medição e do segredo da API em Marketing → Rastreamento. |
| **Enviar conversão para o Google Ads** | Registra uma conversão offline do contato numa ação de conversão da conta conectada em Marketing → Anúncios, pelo clique que trouxe o lead (gclid guardado na atribuição). Opcionalmente manda e-mail e telefone com hash (conversões otimizadas para leads), o que vale também para quem não veio de um clique. |
| **Público personalizado da Meta** | Inclui ou tira o contato (e-mail e telefone com hash SHA-256) de um público personalizado da Meta, para anunciar para ele ou excluí-lo dos anúncios. O ID do público fica no Gerenciador de Públicos. Precisa do Meta Ads conectado em Marketing → Anúncios. |

## IA

| Ação | Para que serve |
| --- | --- |
| **Bot de IA na conversa** | Um agente de IA publicado lê a conversa com o contato e responde à última mensagem dele, com a base de conhecimento do agente. Ele passa a conversa para a equipe quando o cliente pede uma pessoa ou quando não sabe responder, encerra quando o cliente se despede e, com um serviço escolhido, oferece horários livres e marca o escolhido. A resposta fica em `{{vars.nome}}`. |
| **Ligar ou desligar o bot de IA** | Liga o bot de IA na conversa do contato: cada mensagem nova do cliente recebe a resposta do agente, até ele passar a conversa para a equipe, encerrar o atendimento ou ser desligado. As respostas usam a OpenAI de quem salvou este fluxo ou, sem a chave, a IA gratuita da graao, quando liberada. Desligar também tira o bot da conversa. |
| **Rodar agente de IA** | Manda uma mensagem para a versão publicada de um agente de IA desta subconta (com a base de conhecimento e a memória dele) e guarda a resposta em `{{vars.nome}}`. A execução aparece no histórico do agente. |
| **Perguntar à IA** | Pede qualquer tarefa à IA com as suas palavras (escrever, reescrever, classificar, responder) e guarda o resultado em `{{vars.nome}}`. O texto de apoio vai como dado para a IA analisar, nunca como instrução. |
| **Gerar imagem com IA** | Cria uma imagem a partir de uma descrição (OpenAI gpt-image-1) e guarda em Arquivos, com um link público em `{{vars.nome}}` para mandar por WhatsApp, e-mail ou post. Usa a OpenAI de quem salvou o fluxo. |
| **Gerar vídeo com IA** | Cria um vídeo curto a partir de uma descrição (OpenAI sora-2). Leva alguns minutos: o fluxo espera o vídeo ficar pronto e guarda o link público em `{{vars.nome}}`. Usa a OpenAI de quem salvou o fluxo. |
| **Decidir com IA** | A IA escolhe uma das opções. Use a variável num Se / Senão ou Roteador. |
| **Resumir com IA** | Resume uma conversa ou um texto em poucas linhas. |
| **Detectar intenção com IA** | Classifica a mensagem numa das intenções. Sem encaixe, a variável fica “outra”. |
| **Traduzir com IA** |  |
| **Extrair dados com IA** | Cada dado vira `{{vars.nome}}`. Use “Atualizar campo do contato” depois para gravar. |
| **Analisar imagem com IA** | Descreve ou responde uma pergunta sobre uma imagem pública (https). |

## Fluxo

| Ação | Para que serve |
| --- | --- |
| **Aguardar** |  |
| **Definir data do evento** | Guarda a data (e a hora) de um evento do contato, como uma consulta, um webinar ou uma entrega. As etapas Aguardar "em relação à data do evento" contam a partir dela. Aceita variáveis e datas como 2026-12-01 19:30 ou 01/12/2026 19:30, no fuso da subconta. Fica em `{{vars.data_evento}}`. |
| **Se / Senão** |  |
| **Filtro** | Só continua se a condição for verdadeira |
| **Definir variável** | Guarda um valor para usar depois como `{{vars.nome}}` |
| **Roteador** |  |
| **Teste A/B** | Divide os contatos entre caminhos por percentual, para comparar mensagens, ofertas ou tempos de espera. Cada contato cai em um caminho por sorteio. |
| **Repetir (loop)** | Roda as etapas de dentro uma vez para cada item de uma lista (ou um número de vezes) e depois segue o fluxo. Dentro, use `{{vars.item}}`, `{{vars.item_numero}}` e `{{vars.item_total}}`. Até 50 repetições. |
| **Liberar em lotes** | Deixa passar só um lote de contatos a cada intervalo; os outros esperam a vez nesta etapa. Útil para não disparar tudo de uma vez. |
| **Evento de meta** |  |
| **Ir para outra etapa** |  |
| **Disparar evento personalizado** | Dispara um evento com nome e dados. Os fluxos com o gatilho Evento personalizado de mesmo nome começam na hora, com este contato (se houver) e os dados em `{{trigger.campo}}`. Limites: o fluxo não dispara a si mesmo, até 5 eventos por execução, até 3 fluxos em sequência e até 50 fluxos por cascata. |
| **Adicionar a outro fluxo** |  |
| **Remover de um fluxo** |  |
| **Remover de todos os fluxos** | Tira o contato de todos os fluxos em que ele está rodando ou esperando. |
| **Código personalizado** | Calcula valores com a linguagem de expressões da Graao, uma linha por variável: nome = expressão. Cada linha pode usar as anteriores pelo nome, o contato (contact), o gatilho (trigger), as variáveis (vars) e as etapas (steps); as próximas etapas leem o resultado em `{{vars.nome}}`. Roda isolado, sem rede e sem disco. Ex.: total = number(trigger.total) * 0.9 |
| **Operação matemática** |  |
| **Formatar texto** |  |
| **Formatar data** | Guarda uma data formatada em `{{vars.nome}}`. Aceita AAAA-MM-DD, data com hora ou a palavra hoje. |
| **Formatar número** | Guarda um número formatado em `{{vars.nome}}`. |
| **Janela de atendimento do WhatsApp** | Confere se o contato mandou WhatsApp nas últimas 24 horas (a janela de atendimento). Guarda aberta ou fechada em `{{vars.nome}}` e os minutos que restam em `{{vars.nome_minutos}}`, para usar num Se / Senão. |
| **Formatar lista** | Trata um texto como lista (itens separados por vírgula ou outro separador) e guarda o resultado em `{{vars.nome}}`. |
| **Webhook de saída** |  |
| **Webhook personalizado** | Chama uma API com o método, os cabeçalhos e o corpo que você escrever (todos aceitam variáveis) e espera a resposta: o corpo fica em `{{vars.nome}}`, o código HTTP em `{{vars.nome_status}}` e, numa resposta JSON, cada campo simples em `{{vars.nome_campo}}`. Só endereços https públicos. |
| **Encerrar fluxo** |  |
